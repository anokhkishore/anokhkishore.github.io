# Anokh Kishore profile site

Static GitHub Pages-ready site.

## Publish
1. Upload all files/folders in this directory to the repository root.
2. GitHub repository Settings -> Pages -> Deploy from a branch.
3. Select `main` and `/ (root)`.

## Privacy
The page includes `noindex`, `nofollow`, `noarchive`, `nosnippet` and a `robots.txt` crawl block. GitHub Pages itself remains publicly accessible to anyone with the URL. Selected certificate previews have employer-specific lines visually obscured to keep the page employer-neutral.
